### 🌌 Sobre Mim

Olá! Sou o **Leandro Amarante**, atualmente cursando **Engenharia Informática e de Computadores na UniCV**.

Minha abordagem ao desenvolvimento combina a precisão da engenharia com uma estética minimalista. Busco criar soluções que sejam tecnicamente robustas, mas visualmente limpas e intuitivas. Acredito que o código deve ser tão elegante quanto a interface que ele sustenta.
